# Local STT model comparison

This is an isolated diagnostic project, deliberately outside `BlueJays.slnx`.
It does not change application settings, add engines to the UI, capture/play audio,
or call an API. Model weights and raw results live in ignored `artifacts/model-comparison/`.

Dependencies: .NET 10, official sherpa-onnx 2.0.1 (ONNX Runtime 1.28.2),
Whisper.net 1.9.1 via the app reference, and Parquet.Net 6.1.0 for fixture extraction.
NuGet versions and dependency hashes are locked in this project's lock file.

## Reproduce

Run from the workspace root, using one model process at a time:

```powershell
dotnet restore tests/BlueJays.ModelBench --locked-mode
dotnet build tests/BlueJays.ModelBench -c Release --no-restore
$bench = '.\tests\BlueJays.ModelBench\bin\Release\net10.0-windows\win-x64\BlueJays.ModelBench.exe'
& $bench prepare
& $bench fleurs
& $bench sensevoice artifacts/model-comparison/models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17 artifacts/model-comparison/manifest-fleurs-ja.json artifacts/model-comparison/results/sensevoice-cpu-fleurs.json
& $bench qwen artifacts/model-comparison/models/sherpa-onnx-qwen3-asr-0.6B-int8-2026-03-25 artifacts/model-comparison/manifest-fleurs-ja.json artifacts/model-comparison/results/qwen-cpu-fleurs.json
& $bench whisper-small models/ggml-small-q5_1.bin artifacts/model-comparison/manifest-fleurs-ja.json artifacts/model-comparison/results/whisper-small-vulkan-fleurs.json provider=vulkan
& $bench whisper-base models/ggml-base-q5_1.bin artifacts/model-comparison/manifest-fleurs-ja.json artifacts/model-comparison/results/whisper-base-vulkan-fleurs.json provider=vulkan
& $bench whisper-routed models/ggml-small-q5_1.bin artifacts/model-comparison/manifest-fleurs-ja.json artifacts/model-comparison/results/whisper-routed-vulkan-fleurs.json provider=vulkan
```

Replace the manifest with `manifest.json` for the original/noise conditions.
`manifest-lunch.json` is a one-clip subset generated by `prepare` for thread tuning;
it is the first entry of the demo manifest. Optional arguments: `threads=1|2|4|6`
(sherpa only), `runs=3`, `fixed` (SenseVoice only, for a single-language manifest).
Whisper base/small use each clip's known language; routed Whisper retains English
and Japanese as candidate spoken languages, including on the Japanese-only subset.
SenseVoice and Qwen use their built-in automatic language handling.

The tool measures initialization separately, then one first decode and three warm
decodes per clip. The median of those warm decodes is reported. Timings include
native feature extraction/inference and text retrieval, exclude file I/O/model
loading, and exclude UI, VAD buffering, network translation and context correction.
Files are converted consistently to 16 kHz mono, with no external preprocessing
or glossary. Six CPU inference threads are used unless explicitly overridden.
The Whisper baseline uses the application's own DC-removal/bounded-gain preparation;
the ONNX models use their runtime frontends. This compares actual engine pipelines,
not identical internal feature tensors.

Japanese CER removes punctuation/whitespace, applies Unicode NFKC and lowercasing,
then computes character-level Levenshtein distance. Kanji/kana and numeric spelling
differences remain errors; this measures orthographic transcription, not meaning.
English WER uses lowercased alphanumeric words with apostrophes removed. Corpus CER
must be total errors / total reference characters, rather than a mean of percentages.
Working-set measurements are process RAM, not combined host/GPU memory.

`self-test` checks normalization, a Japanese homophone substitution, edit distance
and English word tokenization. After all result files exist, `report` regenerates
`tests/BlueJays.ModelBench/RESULTS.md` and `artifacts/model-comparison/metrics.csv`.
The report expects the ten-clip and demo result pairs above, plus thread-count files
named `<sensevoice|qwen>-cpu-threads-<1|2|4|6>.json`, made with `manifest-lunch.json`.

These short read-speech samples do not establish meeting accuracy or sustained
capture-to-caption latency. The app has not been switched to either new model.

## Hardware probe

`tests/BlueJays.OpenVinoProbe` is separate so the Intel GPU plugin does not alter
sherpa's CPU runtime. It uses official ONNX Runtime 1.31.1 and Intel's OpenVINO
plugin 1.8.1. Its default command enumerates devices. An optional ONNX model path
tests session creation only; successful compilation is not an ASR GPU benchmark.

The standard sherpa-onnx 2.0.1 Windows NuGet runtime used here reports only
`CPUExecutionProvider`. Requesting `openvino:tests/BlueJays.ModelBench/openvino-gpu.config`
explicitly logs CPU fallback. Do not label that run as GPU inference. Intel's
separate plugin can enumerate this laptop's Iris Xe GPU, but end-to-end accelerated
SenseVoice/Qwen transcription has not been measured. The existing app's Vulkan
runtime serves Whisper models, not these ONNX graphs.

Model licenses are separate from runtime licenses: SenseVoice's model card points
to the [custom FunASR model license](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE),
while [Qwen3-ASR](https://huggingface.co/Qwen/Qwen3-ASR-0.6B) is Apache-2.0.
No claim is made that every model weight is under the runtime's MIT/Apache license.
